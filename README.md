# SmartMealPlanner SaaS

Meal planning SaaS with onboarding and shopping lists.

## Features

- Meal planner
- Shopping list
- Onboarding

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/smart-meal-planner.git
cd smart-meal-planner
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint
